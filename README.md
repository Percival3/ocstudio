# OC Studio · 世界观工作台

本地运行的中文网页工具，用画布、关系和时间轴梳理人物、地点与历史。没有账号、云端同步或小说章节编辑器。

## 打开工作台

1. 安装 Node.js 22.12 及以上版本（已在 Node.js 24 下验证）。
2. 双击项目目录中的 `start.cmd`。首次使用需要联网安装依赖，之后运行不需要联网。
3. 在 Chrome 或 Edge 打开 **http://127.0.0.1:4173**。使用期间保留启动窗口，按 `Ctrl+C` 关闭服务。

也可以在项目目录运行：

```powershell
npm.cmd ci
npm.cmd run dev
```

端口固定为 4173，占用时会报错，不会自动换地址。请始终使用 `127.0.0.1`，不要改为 `localhost`；不同地址、端口或浏览器使用独立的本地资料。

## 使用方法

- 左侧创建分类与画布。画布行右侧的省略号可以重命名、移动分类或删除；删除分类只会把画布移入“未分类”。
- 点击顶部“创建”，选择人物、事件、地点、组织、自由节点或时间轴。双击画布空白处也能创建自由节点。
- 拖动节点调整布局；拖动空白处框选，`Shift` 多选；按住空格拖动平移，滚轮缩放。左下角“定位全部内容”回到全图。
- 点击节点，在右侧修改名称、自定义字段和图像。字段可增删、改名、排序，卡片显示前 3 个非空字段。图片最多 20 MB/张，支持 PNG、JPEG、WebP、GIF、AVIF，保留原图。
- 拖动节点四周的连接点到另一个节点建立关系，点击连线标签命名，可切换单向箭头。同一对节点支持多种关系。
- 时间轴是可自由移动、调整宽度的画布对象。其标题栏用于拖动，内部可以横向滚动。条目可以直接填写，也可引用同画布的事件。拖动条目或侧栏把手调整顺序，侧栏上下箭头也可排序。
- 事件模板的“时间”字段默认供时间轴使用。改名或移动这个字段不会断开关联；删除后可在“时间轴使用的时间字段”中重新指定。
- 删除事件时，关联时间轴条目会变成独立记录，保留名称、时间与说明；删除时间轴条目不会删除事件。
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` / `Ctrl+Y` 重做，`Delete` 删除选中对象。输入框内使用键盘不会触发画布删除。撤销记录最多保留 80 步，连续输入合并，切换画布后清空。

## 保存与备份

资料与图片保存在当前浏览器的 IndexedDB 中，编辑后自动保存；顶部显示保存状态，保存失败可点击重试。关闭页面前请等待“已保存到本机”。

数据不在项目文件夹中。浏览器开发者工具的 Application（应用）→ IndexedDB → `oc-studio-v1` 可查看数据：`workspace` 保存工作台结构与文字，`assets` 保存图片。底层文件由浏览器用户配置目录管理，不建议直接复制或修改这些数据库文件。上传 GitHub 只会上传程序源码，不会上传浏览器里的世界观资料。

**清除网站数据、删除浏览器用户配置或使用隐私模式可能丢失资料。** 请定期通过顶部“备份 → 导出全部资料”保存 JSON 文件，其中包含所有分类、画布、关系、时间轴与正在使用的原始图片。

导入会验证版本、引用、重复 ID 和图片数据，显示数量后再确认替换整个工作台。恢复失败时保留原有资料。备份不是合并导入，请先导出当前资料。

## 开发与检查

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run test:e2e
```

浏览器测试使用本机安装的 Google Chrome（Playwright `channel: chrome`）。测试使用隔离浏览器上下文，不触碰日常浏览器资料。

`test-results/` 和 `playwright-report/` 是可随时删除的测试截图、日志与报告，已被 Git 忽略。`src/model.test.ts` 和 `tests/` 是可复用的测试源码，保留在仓库中，但不会打包进正式应用。工作台导出的 `OC-Studio-*.json` 备份也被 Git 忽略。

- `src/model.ts`：领域类型、模板、引用解析和备份完整性检查。
- `src/store.ts`、`src/storage.ts`：编辑与撤销、串行保存、IndexedDB 和备份。
- `src/components/`：画布、节点、时间轴与属性编辑。

生产构建产物在 `dist/`；可停止开发服务后运行 `npm.cmd run preview`，仍使用相同的本地地址。应用不依赖外部字体、图片服务或远程 API。
